# Manuskripte

Hier liegen die Texte der Folgen als Markdown-Dateien, z. B. `folge-01.md`, `folge-02.md`.

- Ein Manuskript pro Folge, Dateiname passend zur Folgennummer.
- Aufbau einer Folge: kurze Erklärung → Prüfungsfrage → Pause zum Mitdenken → Antwort → Merksatz. Am Ende die 3 wichtigsten Merksätze.
- Für die Vertonung den Text in Teile mit **höchstens 5.000 Zeichen** schneiden (Teil a, b, …). Die Teile im Manuskript am besten mit `## Teil a`, `## Teil b` markieren, damit man später weiß, welcher Text in welcher MP3 steckt.

**Folge 1 „Lichter und Signale“:** Das Manuskript liegt bisher nur im Claude-Projekt „Bootsführerschein“ (als Audio). Sobald der Text vorliegt, kommt er als `folge-01.md` hierher.
