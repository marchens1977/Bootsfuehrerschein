# ⚓ Bootsführerschein-Podcast

Eine Hör-App für selbst erstellte Lern-Podcasts zum **Sportbootführerschein Binnen und See**.
Gemacht zum Lernen im Auto oder abends: große Knöpfe, dunkles Design, Weiterhören, Sperrbildschirm- und Lenkradtasten-Steuerung, offline nutzbar.

**👉 App öffnen:** https://marchens1977.github.io/Bootsfuehrerschein/

## Was die App kann
- Liste aller Folgen (Nummer, Titel, Bereich Basis / See / Binnen, Länge), filterbar
- Eine Folge kann aus mehreren MP3-Teilen bestehen – sie spielt trotzdem wie *eine* Folge
- Merkt sich die Stelle jeder Folge, großer Knopf „Weiterhören“
- Status je Folge: neu, angefangen, fertig, wie oft komplett gehört
- ±15 Sekunden, vorige/nächste Folge, Geschwindigkeit 0,8x–1,5x
- Automatisch weiter oder Folge wiederholen
- Steuerung über Sperrbildschirm und Auto-Bluetooth
- Fortschritt als Datei sichern und wieder einlesen
- Auf dem Startbildschirm installierbar, Folgen offline speicherbar

## GitHub Pages einschalten (einmalig)
1. Auf github.com das Repository öffnen → **Settings** (Zahnrad, evtl. im „…“-Menü).
2. Links bzw. im Menü **Pages** antippen.
3. Bei **Source**: „Deploy from a branch“. Bei **Branch**: `main` und Ordner `/ (root)` → **Save**.
4. Nach 1–2 Minuten ist die App unter dem Link oben erreichbar.
